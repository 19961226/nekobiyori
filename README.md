# 保護猫カフェ ねこびより｜サイトデータ

## 確認方法
`index.html` をブラウザ（Chrome推奨）で開いてください。
スマホ表示は、デベロッパーツールのデバイス表示（幅390pxなど）で確認できます。

## フォルダ構成
- `*.html` … 13ページ（index / about / guide / menu / price / cats / staff / faq / news / news-detail / access / reserve / privacy）
- `scss/` … SCSS（`style.scss` が各パーシャルを読み込みます）
- `css/style.css` … SCSSのコンパイル結果
- `js/main.js` … 全ページ共通のJavaScript（猫のデータ・カレンダーの定休日もここ）
- `images/` … 仮画像（SVG）

## SCSSのコンパイル
```
npx sass scss/style.scss css/style.css --no-source-map
```

## 画像の差し替え（ChatGPTで生成した画像）
1. `images/` に、仮画像と**同じファイル名**で保存します（例：`hero-main.jpg`）
2. 拡張子を変えた場合は、HTMLを一括置換します
   - 検索：`.svg"`　置換：`.jpg"`（※ ロゴ `logo.svg` は制作済みのため置換しない）
3. 猫の写真の拡張子は `js/main.js` 冒頭の `IMG_EXT` で指定しています（現在は `'.jpg'`）

## トップのスライドショー
- 切り替え間隔：`js/main.js` の `HERO_INTERVAL`（初期値 6000＝6秒）
- フェードの長さ：`scss/_pages.scss` の `.hero__slide` の `transition`（初期値 1.6秒）
- 枚数を変える場合は、`index.html` の `.hero__slide` と `.hero__dot` を同じ数だけ追加・削除
- 「視差効果を減らす」設定の端末では自動再生しません（ドットで切り替え可能）

## ロゴ
`images/logo.svg` はオリジナル制作のロゴです（日なたの円＋ひなたぼっこする猫のマーク、文字はアウトライン化済み）。

## 仮で入れている内容（公開前にクライアント確認）
- ドリンク・焼き菓子の商品名と価格（各5品）
- キャンセル・変更について（`reserve.html`）
- FAQの回答（予約・子ども・抱っこ・アレルギー・駐車場）、利用ルール（撮影・アレルギー・抱っこ）
- お客様の声（3件・掲載イメージ。オープン後に実際の声へ差し替え）
- 猫の年齢・保護の経緯・譲渡状況（6匹・サンプル。名前と性格はCanvaチラシより）、お知らせ（サンプル）

## まだ決まっていない情報（縞模様の枠 `.ph` で表示）
- 住所の番地・建物名、地図（`access.html` と `index.html` の iframe）
- 代表メッセージ、保護活動の内容、スタッフ名・ひとこと
- 譲渡条件・審査内容、お支払い方法、最寄り駅からの道順
- 臨時休業日 … `js/main.js` の `CLOSED_DATES` に追加

## 予約の受け付け
予約サービスは導入せず、`reserve.html` のフォームで受け付けます（現在はデモのため送信されません）。
WordPress化の際に、Contact Form 7 などのフォームプラグインへ置き換えてください。

## WordPress化の目安
HTML内の `<!-- ▼WP化：〇〇 -->` 〜 `<!-- ▲WP化：〇〇 -->` が、テンプレート化・ループ化する範囲です
（お知らせ一覧・詳細、猫の紹介、店舗情報・営業時間、営業カレンダー）。
